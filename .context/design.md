# Design System

## 🎨 Color Scheme
- **Primary**: Industrial/Professional tones (likely based on Tailwind defaults).
- **Secondary**: High-contrast accents for call-to-actions.
- **Backgrounds**: Clean, modern aesthetic with ample white space.

## 🖌 UI Elements
- **Typography**: Clear, readable fonts suitable for technical specifications.
- **Components**: Radix UI primitives and Tailwind CSS styling.
- **Visuals**: High-quality product images and intuitive iconography (Lucide React).

## ✨ User Experience
- **Interactive**: Smooth transitions using Framer Motion (Motion).
- **Feedback**: Immediate visual cues for cart actions and form submissions.
- **Accessibility**: ARIA-compliant components for inclusive usage.
